# Paper-to-code and result map

## Manuscript

**Limits of monthly PM₂.₅ exposure assignment across space and time and implications for gallbladder and bile duct disease research**

Shuo Feng, Chao Shi, Tianming Liu, Haoran Ding, Fenghe Hang, Zhenghao Huang, and Xianzhi Meng.

This code package concerns exposure-estimate validation. It contains no disease outcome cohort and does not estimate biliary or pancreatic disease associations. The repository is https://github.com/FENG1567/monthly-pm25-exposure-validation; the manuscript-associated software version is v0.1.0. No DOI has been assigned.

## Archived code and adapters

The `analysis/original/` tree preserves historical validation, Portugal validation, LOCO, global contrast checks, component-specific extras, final supplementary selection/reduction scripts, and auxiliary smoke/HMS/grid code. `analysis/original/SOURCE_SNAPSHOTS.json` records original and distribution hashes and declares path-only redactions. The portable adapter in `src/pm25_repro/analysis.py` constructs constrained commands for explicit inputs; it does not rewrite the original model algorithms or select an analysis by score.

| Component | Archived runner |
|---|---|
| Historical | `analysis/original/historical/validation/run_validation.py` |
| Portugal | `analysis/original/portugal/validation/run_validation.py` |
| Future year | `analysis/original/historical/validation/run_external_year.py` |
| LOCO | `analysis/original/loco/validation/run_loco.py` |
| Additional archived tools | `analysis/original/extras/` |
| Final result reduction and panel selection | `analysis/original/supplementary/` |
| Smoke/HMS diagnostics and saved-grid generation | `analysis/original/auxiliary/` |

The auxiliary archives retain scientific implementation and its validation dependencies;
they require external predictions, features and provenance contracts. They are not
additional one-command portable runners. The grid writer's original SHA-256
`0049035bb798ddeede6100b8391975660d99f2a5b1f7438bf4b687ef1f8038e4`
and builder's original SHA-256
`317723ad77c7927ad99f3b6b594839f24c7df4ddea6c89180ad9a75a283ffd5c`
are bound in the saved final grid materialization record.

`src/pm25_repro/derive.py` performs additional numerical replay from the public
aggregate tables: 64 folds to 16 pooled conformal groups, 96 monthly metric
differences, directions of 78 saved simultaneous intervals, and the exact 24-row
annual SatPM selection. This does not recreate bootstrap intervals.

The adapter requires repository-relative, explicit input paths; an analysis command prints a plan unless `--execute` is specified. See [Reproducibility](REPRODUCIBILITY.md) for configuration and the incomplete raw-to-result mappings.
