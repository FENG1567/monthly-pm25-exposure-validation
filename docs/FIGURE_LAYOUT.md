# Figure layout and typography

The fourteen reference figures use uppercase 18 pt Arial Bold panel labels,
bold text, aligned panel areas and reserved legend/annotation spaces. All
numerical panel inputs retain their prior bytes. The rendering update fits no
model and computes no new uncertainty interval. Supplementary Figure S7 keeps
the full source stream and the same primary finite points; A–D identify the
United States and E–H Canada, ordered January, April, July and October.

The figure replay writes editable PDF/SVG, 300 dpi PNG and 600 dpi LZW TIFF
files. Arial must be available to reproduce the supplied typography. Install
it under its applicable font licence, or set PM25_FIGURE_FONT_DIR to a local
directory containing arial.ttf and arialbd.ttf before rendering. Font files
are not bundled. The supplied PDFs embed the rendered Arial Bold subsets.

The source figure data, paired estimates, intervals, scale definitions and
category mappings are unchanged. The main figure dispatch explicitly maps
feature increments to Figure 3, fire support to Figure 4 and calibration to
Figure 5. Registry captions use the same uppercase panel references as the
manuscript. Data and code retain the existing CC BY 4.0 and MIT terms.

English figure captions are provided in [caption_en.md](caption_en.md).

Reader-facing labels identify station-months, validation records and physical units.
The feature contrast is written full minus (B+AOD), and the figure captions define
the predictor/task codes and interval constructions used in each display. Sparse
grid support, conditional uncertainty and missing HMS dates retain their original
scientific interpretation. [Figure captions](caption_en.md) match the manuscripts.
